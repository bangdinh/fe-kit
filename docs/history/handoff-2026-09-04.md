## ⑤ Một việc còn nợ từ phiên trước

`cmd/scaffold/main.go` ghi mọi file bằng `os.WriteFile(..., 0644)` nên **6 file `.sh`** sinh
ra mất bit executable (`deploy/entrypoint.sh`, 3 `docker-entrypoint*.sh`, `scripts/release.sh`,
`jira.sh`). Dockerfile đã `chmod +x` cho entrypoints nên container không sao, nhưng
`scripts/release.sh` và `jira.sh` phải gọi qua `bash <file>`. Mình **không sửa** vì file đó
đang trong danh sách bạn sửa dở. Fix là một nhánh nhỏ ở `walkTemplates`: tên kết thúc `.sh`
thì ghi `0755`.
